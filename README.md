# AtivaEdu Funcional

Versão pronta para publicar no GitHub, Netlify ou Vercel.

Funciona:
- cadastro e login;
- criação de atividades;
- questões objetivas, discursivas e mistas;
- gabarito;
- histórico;
- exclusão;
- impressão e PDF;
- opção TEA/TDAH.

Observação: nesta versão inicial, os dados ficam no navegador usando localStorage.
